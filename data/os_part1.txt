Module: Operating Systems - Memory Management
Topic: Paging and Virtual Memory

Paging is a memory management scheme by which a computer stores and retrieves data from secondary storage for use in main memory. In this scheme, the operating system retrieves data from secondary storage in same-size blocks called pages. 

Key Concepts:
1. Page Size: Typically 4 KB in standard x86 architectures.
2. Page Table: A data structure used by a virtual memory system in a computer OS to store the mapping between virtual addresses and physical addresses.
3. Page Fault: An interrupt raised by hardware when a running program accesses a memory page that is not currently mapped by the memory management unit (MMU) into the RAM.

Handling Page Faults:
Step 1: The hardware traps to the OS kernel.
Step 2: The OS checks if the memory reference was valid. If invalid, terminate the process.
Step 3: Find a free frame in physical RAM.
Step 4: Read the desired page from disk into the allocated frame.
Step 5: Update the Page Table entry.
Step 6: Restart the instruction that was interrupted by the page fault.
